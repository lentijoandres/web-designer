**Mantiz Web Designer**

Guidelines for this project.

# General

* Preserve Mantiz branding, colors and typography (DSM tokens in `src/styles/theme.css` and `@mantiz/ui-theme`).
* Keep layouts structured with flexbox/grid; avoid absolute positioning unless necessary.
* Do not reintroduce other Mantiz products (POD, Mantiz v7, MCA) or app launchers into this codebase.

# Design system

* Base accent for Web Designer: `#1F7FB2`
* Primary text / navy: `#163A53`
* Background: `#F7F9FB`
* Use Montserrat / Inter as established in existing screens.
